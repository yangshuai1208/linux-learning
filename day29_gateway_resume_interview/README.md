## 项目名称

Linux IoT Gateway 物联网网关项目

## 项目定位

本项目是一个基于 Linux C 的物联网网关 Demo，模拟 STM32 设备上传温湿度数据，Linux 网关负责数据读取、数据解析、JSON 构建、传感器日志保存、MQTT 发布、系统运行日志记录和运行统计报告生成。
